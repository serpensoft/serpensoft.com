iWriter Pro

An elegant and minimalist text editor with built-in Markdown support.

Distraction-free and subscription-free.

Clean and Simple

iWriter Pro is designed to be easy yet powerful text editing app. It provides distraction-free writing experience with a bunch of handy features.

Markdown Highlighting

Markdown is a good way to format your text, apply styles, insert lists, and block quotes. iWriter Pro automatically highlights text as you type.

iCloud Support

Use iCloud to store your documents. You can easily create, view, and edit your files on Mac, iPad, and iPhone devices.

Everything in iWriter Pro

Writing

  • Clean and minimal interface
  • Text editing with live Markdown syntax highlighting
  • Typewriter mode with focusing on line, sentence, or paragraph iPad & Mac
  • Editor, Preview, and Split modes, with scroll synchronization Mac
  • Counters for words, characters, sentences, and paragraphs
  • Automatic number, bullet, and task list formatting
  • Keyboard shortcuts for text formatting and quick navigation
  • Search and Replace in your documents
  • Fast and responsive editing even for large files

Markdown and preview

  • HTML Preview for Markdown and MultiMarkdown documents
  • Highlighting and rendering of LaTeX equations
  • Flowchart and Mermaid diagrams
  • Source code highlight in HTML preview
  • Light and dark layouts, with automatic switching

Files and sync

  • iCloud sync across iPhone, iPad, and Mac
  • Powerful Document Browser with tags support iPhone & iPad
  • QuickLook plugin for previewing documents in Finder Mac
  • Export as HTML, PDF, RTF, EPUB, LaTeX, and DOCX
