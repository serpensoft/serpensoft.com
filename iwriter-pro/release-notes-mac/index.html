4.4.1
#

  • Mermaid code blocks now support syntax highlighting.

  • Preview plugins updated: MathJax (3.2.2), Mermaid (9.1.3).

  • Other minor bug fixes and improvements.

4.4
#

  • Mermaid code blocks now support syntax highlighting.
  • Syntax highlighting for LaTeX and HTML was updated.
  • Preview plugins updated: MathJax (3.2.2), Highlight.js (11.5.1).
  • Fixed crash in files containing multiple strikethrough style elements.
  • Other minor bug fixes and improvements.

4.3
#

  • Major improvements to the scroll-sync feature.
  • Fixed issues with scrolling positions in Split mode.
  • Fixed some bugs with text scrolling positions when switching the editing mode.
  • Several shortcuts have been updated.
  • “Insert Footnote” action added to the menus.
  • CMD + Enter shortcut now inserts a backslash at the end of the line.
  • Preview plugins updated: Mermaid (9.0.1) and Highlight.js (1.15.1).
  • Other minor bug fixes and improvements.

4.2.2
#

  • Fixed a crash caused by text statistics counters.
  • Resolved issues with document extensions.
  • Fixed bugs in document transclusion.
  • Preview plugins updated: Mermaid (8.14), Flowchart (1.17).
  • Fixed various bugs in DOCX and EPUB export.
  • Other minor bug fixes and improvements.

4.2
#

  • Added syntax highlighting for inline HTML.
  • Syntax highlighting for LaTeX notations updated.
  • Added menu command for reloading Preview (⌘ + R).
  • Implemented various performance improvements for Editor and Preview.
  • Improvements for scrolling in Split mode.
  • Fixed bugs with attached external files and images.
  • Fixed bug with HTML comment highlighting.

4.1
#

  • Added syntax highlighting for LaTeX notations.
  • Performance optimization for Split mode.
  • Editor should be much more responsive during text editing.
  • Fixed bugs with attached external files and images.
  • Fixed various bugs in user interface.
  • The backslash line-break symbol is now colorized.

4.0
#

  • New Dashboard panel with Navigation and Text Statistics.
  • German and Russian localizations added.
  • Preview plugins updated: Mermaid (8.13.4), Flowchart (1.17.0), Highlight.js (11.3.1).
  • Fixed issues with export to DOCX format.
  • Fixed various issues in Focus mode.
  • Various bug fixes and performance improvements.
  • iWriter Pro now requires MacOS 11 or higher.

3.5
#

  • QuickLook plugins for preview and thumbnails updated.
  • It is now possible to navigate with keyboard keys in HTML preview.
  • Fixed issues with export to DOCX format.
  • Fixed issues with export to LaTeX format.
  • Fixed highlighting for strikethrough elements containing sub-items.
  • Fixed highlighting for multi-line Math elements.
  • Mermaid plugin updated to the version 8.12.0.
  • Other minor bug fixes and improvements.

3.4
#

  • QuickLook plugins for preview and thumbnails updated.
  • It is now possible to navigate with keyboard keys in HTML preview.
  • Fixed issues with the behavior of paragraph spacing option.
  • Fixed issues with inserting references to images and external files.
  • Fixed highlighting for strikethrough elements containing sub-items.
  • Fixed highlighting for multi-line Math elements.
  • Mermaid plugin updated to the version 8.12.0.
  • Other minor bug fixes and improvements.

3.3
#

  • Editor’s rendering system updated.
  • Improved text layout and cursor positioning.
  • Maximum available line height value increased.
  • Header labels are now rendered with dimmed colors.
  • Other bug fixes and improvements.

3.2
#

  • Mermaid plugin updated to the version 8.10.2.
  • MathJax plugin updated to the version 3.2.0.
  • Highlight.js plugin updated to the version 11.0.1.
  • Fixed formatting for tabulated lists.
  • Text font size and Preview font scale can now be changed via keyboard shortcuts independently.
  • List insert/remove actions now respect spacing at the start of the line.
  • Preview now supports magnification when using trackpad pinch-to-zoom gesture.
  • QuickLook plugin updated.

3.1
#

  • Fixed issues with inconsistent cursor position and height.
  • Text now displays correct selection color when window is inactive.
  • Task list markers are now displayed correctly in PDF, HTML, and EPUB.
  • Mermaid diagrams now use correct colors for export.
  • Export to RTF now works as expected.
  • Resolved other bugs and user-interface issues.

3.0
#

  • App icon updated to match the Big Sur style.
  • New export option: DOCX (MS Word).
  • Added support for code highlight within HTML preview.
  • You can now change the font of code blocks in editor.
  • Preview settings now allow you to switch the color theme, font, and header alignment.
  • Colors and HTML preview styles for code blocks updated.
  • QuickLook plugin updated with support for system dark mode.
  • Fixed several issues with HTML export.
  • Code line numbers option removed.
  • Resolved various bugs and user-interface issues.

2.3
#

  • Added numbered lists auto-formatting. Ordered lists will maintain the correct marker number when you insert or delete a list item. Automatic formatting is supported by nested lists as well.
  • All list elements now auto-indent multi-paragraph text items. This change is needed to maintain consistency between Markdown source and HTML preview.
  • Added new settings options for line height, paragraph spacing, and indentation.
  • List insertion shortcuts can now be applied to several lines at once.
  • Added option for displaying code line numbers in HTML preview.
  • Colors and HTML preview styles for code blocks updated.
  • QuickLook plugin updated with new style for code blocks.å
  • Resolved various user-interface issues.

2.2
#

  • Added highlight for header links: # Header [link].
  • Header labels are now hidden in Navigation view.
  • Mermaid plugin updated to version 8.9.1.
  • Flowchart plugin updated to version 1.14.1.
  • MathJax plugin updated to version 3.1.2.
  • Fixed issue with System font being unavailable in settings.
  • App icon updated.

2.1.5
#

  • Swap lines easily with new shortcuts: ⌥+⌘+↑ and ⌥+⌘+↓.
  • You can now use the Tab/Shift+Tab shortcuts for text indentation.
  • Additional improvements for Navigation panel.
  • Additional under-the-hood updates.
