#

iWriter 2

An *elegant* and **minimalist** Markdown text editor designed for ==distraction-free writing==.

iPhone / iPad / Mac

> “Simple & beautiful”

App Store Review, 2019

> “Terrific Writing and Notes App”

App Store Review, 2014

Immerse yourself in a **minimalist writing environment** designed to enhance _focus and productivity_. Say hello to **structured, professional documents** that effortlessly transform your ideas.

## MultiMarkdown Support

iWriter 2 is a full-featured Markdown editor built for ==precision and flexibility==.

  • - MultiMarkdown support with live preview and syntax highlighting.
  • - Wikilinks and Wiki-Embeds for connected notes.
  • - Task lists and code blocks made simple.
  • - Keyboard shortcuts for fast inline formatting.

## Built-in Document Manager

A built-in document manager that lets you easily organize, browse, and manage ==all your files in one place== — complete with powerful document search to quickly find exactly what you need.

## Rebuilt with TextKit 2

iWriter 2 has been completely rebuilt from the ground up using Apple's modern TextKit 2 framework, delivering ==faster performance, smoother scrolling==, and a more responsive writing experience.

## Multiple Export Options

A refined, user-friendly interface designed for focus and productivity, offering intuitive formatting options and seamless export to multiple formats including `HTML`, `PDF`, `EPUB`, `DOCX` (Microsoft Word), and `LaTeX`.

## LaTeX Equations

iWriter 2 offers LaTeX syntax highlighting, making ==complex math expressions easy to read and edit== as you write, right inside your Markdown workflow.

## Mermaid Diagrams

iWriter 2 supports Mermaid diagrams, letting you create ==flowcharts, sequence diagrams, and more== using simple text-based syntax, keeping technical writing and visual documentation in one place.

## Focus Mode

Focus on important things. Everything but the ==line, sentence, or paragraph== you're writing fades away. _Try it here_: pick a mode, then click any line to move the cursor.
