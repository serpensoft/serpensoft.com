# MultiMarkdown Syntax Guide

Everything you can type in iWriter 2: the Markdown you write, and what it turns into. Copy any example into a document to try it.

01

Headings

To create a heading, add one to six # symbols before your heading text. The number of # you use will determine the hierarchy level and typeface size of the heading.

02

Text styling

Wrap words in symbols to make them bold, italic, crossed out or highlighted.

03

Paragraphs and line breaks

A blank line starts a new paragraph. To break a line inside a paragraph, end it with two spaces, a backslash or <br/>.

04

Blockquotes

Start a line with > to quote it. Use >> to quote inside a quote.

05

Lists

Start lines with -, * or + for unordered lists, or with numbers for ordered lists. Indent a line to nest it under the one above.

06

Horizontal rules

Put three or more of the same symbol on a line of its own to draw a rule. iWriter 2 has four styles.

07

Escaped characters

Put a backslash before a symbol to show it as typed instead of formatting with it.

08

Links

You can create an inline link by wrapping link text in brackets [ ], and then wrapping the URL in parentheses ( ).

09

Wikilinks

Link to another document in iWriter 2 by its name, in double square brackets.

10

Images

You can display an image by adding ! and wrapping the alt text in [ ]. Alt text is a short text equivalent of the information in the image. Then, wrap the link for the image in parentheses ( ).

11

Image embeds

Show a picture from your folders with ![[ ]]. You can change the image dimensions by adding |200x100 to the link, where 200 is the width and 100 is the height.

12

Tables

Separate columns with | and put a line of dashes under the header. Colons in that line align the columns.

13

Footnotes

Add [^name] where the note belongs, and write the note anywhere in the document.

14

Definition lists

Put a term on one line and its definition on the next, after a colon and spaces.

15

Cross-references

Link to a heading by its text in square brackets, or by an id you give it.

16

Table of contents

Use the {{TOC}} shortcut for a table of contents.

17

Page break

Use 5 or more plus symbols + to add a page break.

18

Document metadata

Put Key: value lines at the very top of the document. They are used when you export, for example as the title and author of a PDF or EPUB.

19

Code

Wrap code in backticks inside a sentence. For a block of code, indent every line with a tab or four spaces, or use a fenced block.

20

HTML

Plain HTML works too, and a <style> block changes how the preview and exports look.
Note Blank lines inside an HTML tag aren’t supported.

21

Math

Write math in LaTeX between $ signs inside a sentence, or between $$ lines for a block.

22

Diagrams

Draw flowcharts, sequence diagrams, timelines and more with Mermaid.

23

Insert other documents

Put the text of another document into the edited one, with MultiMarkdown or wikilink syntax.
Note Only plain text documents can be inserted.

24

Citations

Cite a source with [#name] and list it anywhere in the document. A page number can go first.

25

Abbreviations

Define an abbreviation with [>…].

26

Glossary

Mark a term with [?…] to define it. The definitions are collected in a glossary.

27

Subscript and superscript

^ raises the characters after it and ~ lowers them.
